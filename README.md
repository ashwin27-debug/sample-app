# SmartLab Inventory Management System

PHP + MySQL based laboratory inventory management project.

## Run
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy this folder to `htdocs`.
4. Open phpMyAdmin and import `database.sql`.
5. Open `http://localhost/SmartLab_Inventory_Management_System/`.

## Features
- Dashboard
- Lab management
- Add, edit and delete stock
- Search stock
- Low-stock status
- Responsive UI
